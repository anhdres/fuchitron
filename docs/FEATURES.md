# Features

- Two-team scoreboard with editable names and 14 team colors.
- Two halves, configurable to 10, 15, 30 or 45 minutes each.
- Pause/resume, reload recovery, added-time display, chronological goal history.
- Delete goals with undo; reset match while keeping team customization.
- Text and PNG result sharing, copying and downloads.
- Seven languages: Spanish, English, German, Portuguese, French, Italian, Chinese.
- Installable PWA, offline app shell/fonts, optional screen wake lock.
- On-device persistence with validation and cross-tab edit synchronization.

## Retired

Remote spectator links and their Supabase heartbeat were removed in October
2026. Old `/live/*`, `/s/*`, `/live.html` and `/spectate.html` links redirect to
`/`; the current app does not contact Supabase. Historical audit/feature notes
in the archive describe older releases, not the current feature set.
