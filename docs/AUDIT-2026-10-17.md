# Fuchitron code and UX audit — 2026-10-17

## Scope and baseline

Reviewed all production source files, manifest, service worker, routing,
deployment layout and the Supabase heartbeat. Baseline: `c235134` on `main`.
Production `app.js` matched the local baseline byte-for-byte before changes.
The working tree was initially clean. Remote spectator removal had **not**
reached this revision or production; this release completes that request.

## Confirmed defects and fixes

### Timer and match lifecycle

- Cancelling an end-period confirmation stopped the timer before the answer,
  leaving a stale Pause button. Confirmation now precedes all mutation.
- Reload recovery ran before asynchronous `load()` from `document.fonts.ready`,
  so running matches remained frozen. Restore is now synchronous; font loading
  only refreshes an open image preview.
- Paused goals and ending a paused period used a still-running wall-clock
  anchor. Pause captures elapsed time and clears the anchor; all reads honor
  `running`. Resume reanchors without including the break.
- Ending an unstarted half or operating finished timer controls produced
  impossible states. Explicit `halfStarted` guards and disabled controls now
  match the state machine. Manual score correction remains available.
- Changing half duration during play rewrote historical minute labels. Duration
  is now locked once play starts, and its label clearly says **per half**.
- Timeline and share text disagreed on second-half minute offsets, and the
  full-time share compared second-half duration with a whole-match target.
  Both now use regulation offsets plus added-time notation. Goal/end minutes
  round elapsed seconds up consistently; `0:01–1:00` is minute 1.
- Minute-only sorting could put halftime/fulltime before nearby goals. Timeline
  rendering now groups by half and places end markers after that half's goals.

### Data integrity and safety

- User-supplied team names were inserted into `innerHTML`. Reproduced with
  `<b>unsafe</b>` becoming markup. Timeline content now uses DOM `textContent`;
  goals resolve the current team name instead of stale snapshots.
- `Object.assign()` trusted arbitrary persisted shapes; malformed goals,
  colors, locale, timestamps, or wake-lock handles could break rendering or
  controls. The existing `fuchitron_v4` key is retained with field validation,
  legacy-field migration, goal-ID deduplication and runtime-only wake locks.
- Storage write failures stopped render after mutation. The scoreboard now
  continues in memory and explicitly warns that the match is not saved.
- Undo could reintroduce an old match's goal after New Match; repeated snackbars
  accumulated listeners. Reset/storage replacement clears undo, and one action
  handler is reused.
- Each timer wrote the whole state every second, allowing another tab to
  overwrite recent goals. Ticks now derive time without storage writes; edits
  propagate through storage events. Simultaneous conflicting edits are still
  last-writer-wins, not a transactional multi-user feature.
- Shares used today's date rather than the match date. New matches retain a
  timestamp from the first goal or timer start. Older timestamped matches use
  the available anchor; an old untimestamped match's actual date is unknowable.

### Sharing, language and UI

- Cancelled native sharing opened WhatsApp or downloaded a PNG anyway. An
  `AbortError` now exits, file support is checked with `canShare({ files })`,
  null exports are handled, and download object URLs are released.
- PNG copy now uses promise-valued `ClipboardItem` to preserve user activation.
  Unsupported browsers get the localized download suggestion.
- Long team names broke mobile columns and overflowed image cards. Columns
  can shrink, names wrap on-screen, and canvas text is width-bounded.
- Reproduced main-page overflow at 320 px: document width was 374 px. Header,
  share controls and long translations now fit. Share preview preserves line
  breaks; the canvas keeps its square aspect ratio.
- Dark team colors made role labels unreadable. Those labels use a white
  fallback where needed. Color controls have 44 px targets, labels and selected
  states; keyboard focus and reduced-motion support were added.
- Checkbox state was only populated when opening Share. Settings now render
  the saved value; wake-lock toggles acquire/release immediately. Async request
  races cannot retain a lock after pause/disable. The switch has a full-sized
  interactive target.
- Locale changes now update document language, metadata, accessible names and
  all translated labels. URL language overrides no longer undo a later explicit
  language choice. Update, feedback and timeline text cover all seven locales.
- Unsupported fullscreen controls are hidden. Dialog body sizing respects
  header height/safe areas; backdrop dismissal excludes interior padding.

### Offline, updates and retired live feature

- Removed remote link controls, Supabase requests/credentials, spectator pages,
  live-only translations/styles, and the scheduled heartbeat workflow.
  Legacy live/spectator routes redirect to `/`; no database data was deleted.
- v11 mixed network HTML with stale assets, activated updates immediately,
  cleared unrelated caches, and could resolve failed asset requests to `null`.
  v12 precaches a complete app shell, waits for explicit update/closed tabs,
  limits cache cleanup to Fuchitron, and returns proper fetch responses.
- Typography and an 11-icon subset are self-hosted and precached (183,136 bytes
  of font binaries). Offline startup no longer renders icon ligature words or
  depends on Google Fonts. Licenses are retained in `docs/font-licenses/`.
- Versioned asset queries bypass v11's stale asset entries during migration.
  The worker handles legacy spectator redirects offline too.

## Verification

Automated browser checks use isolated Chrome profiles, not personal data:

- `scripts/audit-regressions.cjs`: 19 regression groups, including timing,
  malformed/blocked storage, names-as-text, undo/reset, localization, wake lock,
  downloads, native-share cancellation, match date and cross-tab synchronization.
- Layout group: 7 languages × 4 viewport widths (320, 375, 768, 1280) × 3 screens
  (main, settings, share) = **84 layout combinations**.
- `scripts/audit-pwa.cjs`: 3 integration scenarios: offline shell/fonts and
  scoring; consent-based update preserving match/unrelated caches; upgrade from
  actual v11 sources preserving the running match and retiring old routes.
- Syntax checks on production JavaScript, `git diff --check`, repository hygiene
  hook, and visual review of narrow-phone and offline screenshots.

The suite asserts no uncaught page errors in regression cases. Offline testing
also asserts no Supabase/Google Fonts requests. Native Safari/iPhone hardware,
real OS share sheets, and battery-saver behavior were not hardware-tested;
those APIs are guarded, with capability checks or graceful fallback.
